
An unofficial GNOME Shell extension that integrates warp-cli into your desktop environment. It provides a quick visual indicator and a dropdown menu in the top bar, allowing you to connect, disconnect, and easily switch between DNS-Only (DoH) and Full VPN modes without opening the terminal.
